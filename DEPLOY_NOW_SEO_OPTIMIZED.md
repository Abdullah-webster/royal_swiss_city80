## 🔧 IF SOMETHING GOES WRONG

### Website shows 404 or blank page
**Fix:** Make sure files extracted to public_html root, NOT in subfolder
1. Delete extracted files
2. Extract ZIP again to current folder (public_html)

### Videos don't play
**Fix:** .htaccess file in public_html should have MIME types
1. In File Manager, check .htaccess exists in public_html
2. If missing, create new file with .htaccess content

### Page loads slow (still 5-10s)
**Fix:** Gzip compression might not be enabled
1. Check .htaccess exists in public_html
2. Contact hosting support: "Enable mod_deflate on my account"

### Contact form doesn't work
**Fix:** Database credentials need to be configured
1. See CPANEL_UPLOAD_INSTRUCTIONS.md
2. Update enquire.php with your database info
